## Privacy review

Before approving any image, verify that it contains none of the following:

- Google Ads account ID or account name
- Email address, username, browser profile, avatar, or bookmarks
- Local filesystem path or cloud-storage location
- Real phone number, license, insurance, website, client name, or campaign data
- Desktop notification, document history, or unrelated application content

Crop or recapture an image rather than blurring a large sensitive region. Remove image metadata before publication and visually inspect the final PNG again.
